# JUCE Autosampler App Development Plan

## Project Overview
A JUCE-based desktop application that automatically samples instruments across a range of MIDI notes, with support for multiple export formats (SF2, SFZ, Decent Sampler). Useful for generating sample libraries from any MIDI instrument connected to the system.

## Phase 2: Core Functionality

### 2.1 MIDI Message Handling
**Location**: `SamplerEngine.cpp`

- Override `processBlock()` to detect incoming MIDI
- Sequence through notes: startNote → endNote
- For each note:
  1. Send MIDI Note On (velocity 100, specified channel)
  2. Wait for `noteDuration` seconds
  3. Send MIDI Note Off
  4. Record audio during entire interval
  5. Move to next note
- Use `Timer` class or audio thread timing for note sequencing

**Implementation Details**:
```cpp
void SamplerEngine::startSampling() {
  currentNoteIndex = startNote;
  recordingBuffer.clear();
  sendMidiNoteOn(currentNoteIndex, midiChannel, 100);
  recordingStartTime = Time::getCurrentTime();
  isRecording = true;
}

void SamplerEngine::processBlock(AudioBuffer<float>& buffer, MidiBuffer& midiMessages) {
  // Handle MIDI input from plugin host
  recordAudioBlock(buffer);
  
  // Check if current note duration exceeded
  if (recordingTime >= noteDuration) {
    storeSample(currentNoteIndex, recordingBuffer);
    sendMidiNoteOff(currentNoteIndex, midiChannel);
    
    if (currentNoteIndex < endNote) {
      currentNoteIndex++;
      recordingBuffer.clear();
      sendMidiNoteOn(currentNoteIndex, midiChannel, 100);
    } else {
      isRecording = false;
      triggerCallback(SamplingComplete);
    }
  }
}
```

### 2.2 Audio Input Recording
**Location**: `RecordingManager.cpp`

- Create circular buffer for real-time recording
- Store samples in `AudioBuffer<float>` per MIDI note
- Handle variable sample rates (44.1kHz - 192kHz)
- Memory management:
  - Pre-allocate max size: `(127-0) * noteDuration * sampleRate * 2 channels * 4 bytes`
  - Example: 128 notes × 3 sec × 44.1kHz × 2ch × 4B = ~66 MB
  - Add UI warnings for high-memory configurations

```cpp
void RecordingManager::recordBlock(const AudioBuffer<float>& inputBuffer) {
  for (int ch = 0; ch < inputBuffer.getNumChannels(); ++ch) {
    currentSampleBuffer.copyFrom(ch, writePosition, inputBuffer, ch, 0, inputBuffer.getNumSamples());
  }
  writePosition += inputBuffer.getNumSamples();
  
  if (writePosition >= maxSamplesPerNote) {
    // Handle overflow: trim to duration
  }
}
```

### 2.3 MIDI Channel Support
- Dropdown selector: 1-16
- Pass channel to MIDI message creation
- JUCE `MidiMessage`: `noteOn(channel, noteNumber, velocity)`
- Validate channel is set before sampling

### 4.2 SFZ Exporter
**Format**: Text-based sampler format (open-source, widely supported)

**WAV Naming Convention**: `{samplePackName}_{NoteName}.wav`
- Example: `MySamples_C3.wav` for MIDI note 48

**File Mapping**:
```cpp
String getMidiNoteName(uint8_t noteNumber) {
  static const char* noteNames[] = {
    "C", "C#", "D", "D#", "E", "F", 
    "F#", "G", "G#", "A", "A#", "B"
  };
  int octave = (noteNumber / 12) - 1;
  int semitone = noteNumber % 12;
  return noteNames[semitone] + String(octave);
}

String getWavFilename(const String& packName, uint8_t noteNumber) {
  return packName + "_" + getMidiNoteName(noteNumber) + ".wav";
}
```

**Implementation**:
```cpp
class SFZExporter : public AudioExporter {
  bool export(const Map<uint8_t, SampleData>& samples, 
              const String& packName,
              const File& dir) override {
    File sfzFile = dir.getChildFile(packName + ".sfz");
    String sfzContent = generateSFZContent(samples, packName);
    
    // Write WAV files for each note
    for (auto& [midiNote, data] : samples) {
      String wavName = getWavFilename(packName, midiNote);
      writeWAVFile(dir.getChildFile(wavName), data);
    }
    
    sfzFile.replaceWithText(sfzContent);
    return true;
  }
  
private:
  String generateSFZContent(const Map<uint8_t, SampleData>& samples,
                            const String& packName) {
    String content;
    content += "<global>\n";
    content += "lovel=0\n";
    content += "hivel=127\n\n";
    
    for (auto& [midiNote, data] : samples) {
      content += "<region>\n";
      content += "sample=" + getWavFilename(packName, midiNote) + "\n";
      content += "key=" + String(midiNote) + "\n";
      content += "pitch_keycenter=" + String(midiNote) + "\n";
      content += "\n";
    }
    
    return content;
  }
};
```

### 4.3 SF2 Exporter
**Format**: SoundFont (binary, complex structure)

**Libraries**:
- Use `libsndfile` or `AudioToolbox` (macOS) for WAV writing
- SF2 requires manual binary structure writing or third-party library
- **Alternative**: Consider using `fluidsynth` library or pre-built SF2 writer

**File Structure**:
```
RIFF Header
├── INFO Chunk (name, copyright)
├── sdta Chunk (audio samples)
└── pdta Chunk (preset definitions)
```

**Implementation Approach**:
```cpp
class SF2Exporter : public AudioExporter {
  bool export(const Map<uint8_t, SampleData>& samples,
              const String& packName,
              const File& dir) override {
    File sf2File = dir.getChildFile(packName + ".sf2");
    
    // Write SF2 binary structure

    // For v1.0, recommend deferring or using libsndfile + custom writer
    
    return writeSF2File(sf2File, samples, packName);
  }
};
```

### 4.4 Decent Sampler Exporter
**Format**: XML-based with embedded audio

**Implementation**:
```cpp
class DecentSamplerExporter : public AudioExporter {
  bool export(const Map<uint8_t, SampleData>& samples,
              const String& packName,
              const File& dir) override {
    XmlElement root("DecentSampler");
    root.setAttribute("version", "1.0");
    
    for (auto& [midiNote, data] : samples) {
      String wavFilename = getWavFilename(packName, midiNote);
      writeWAVFile(dir.getChildFile(wavFilename), data);
      
      XmlElement* sample = root.createNewChildElement("sample");
      sample->setAttribute("path", wavFilename);
      sample->setAttribute("note", midiNote);
      sample->setAttribute("name", getMidiNoteName(midiNote));
    }
    
    File xmlFile = dir.getChildFile(packName + ".dslibrary");
    xmlFile.replaceWithText(root.toString());
    return true;
  }
};
```

### 4.5 WAV File Writing
Use JUCE's built-in utilities:
```cpp
void writeWAVFile(const File& outputFile, const SampleData& data) {
  WavAudioFormat format;
  std::unique_ptr<AudioFormatWriter> writer(
    format.createWriterFor(
      std::make_unique<FileOutputStream>(outputFile),
      data.sampleRate, 
      data.numChannels, 
      16, // bit depth
      StringPairArray(), 
      0
    )
  );
  
  writer->writeFromAudioSampleBuffer(data.audioBuffer, 0, data.audioBuffer.getNumSamples());
}
```

## Phase 6: Technical Considerations

### 6.1 MIDI Output for Desktop App
**System MIDI Output**:
```cpp
class MidiOutputManager {
  void sendMidiNoteOn(uint8_t channel, uint8_t noteNumber, uint8_t velocity) {
    MidiOutput::openDevice(selectedMidiOutputDevice);
    MidiMessage msg = MidiMessage::noteOn(channel, noteNumber, velocity);
    midiOutput->sendMessageNow(msg);
  }
  
  void sendMidiNoteOff(uint8_t channel, uint8_t noteNumber) {
    MidiMessage msg = MidiMessage::noteOff(channel, noteNumber);
    midiOutput->sendMessageNow(msg);
  }
  
private:
  std::unique_ptr<MidiOutput> midiOutput;
  int selectedMidiOutputDevice;
};
```

**Key Differences from Plugin**:
- Access system MIDI outputs via `MidiOutput::getDevices()`
- Create UI dropdown to select target MIDI output device
- Send MIDI from main/UI thread (not audio thread)
- Account for MIDI transmission latency

### 6.2 Audio Input Management
```cpp
class AudioInputManager : public AudioIODeviceCallback {
  void initialise() {
    audioDeviceManager.initialiseWithDefaultDevices(
      2,  // numInputChannelsNeeded
      2   // numOutputChannelsNeeded
    );
    audioDeviceManager.addAudioCallback(this);
  }
  
  void audioDeviceIOCallback(const float** inputChannelData,
                            int numInputChannels,
                            float** outputChannelData,
                            int numOutputChannels,
                            int numSamples) override {
    AudioBuffer<float> inputBuffer((float**)inputChannelData, numInputChannels, numSamples);
    recordingManager.recordBlock(inputBuffer);
  }
};
```

### 6.3 Memory Management
- Pre-allocate sample buffers during setup
- Implement circular buffer with overflow detection
- Clear previous samples when starting new sampling session
- Profile with high note count (e.g., 128 notes × 10 seconds)

### 6.4 Sample Rate Handling
- Query from `AudioIODeviceCallback` setup
- Adjust buffer sizes dynamically if sample rate changes
- Store sample rate with each recording for export

### 6.5 Thread Safety
- Use lock-free queues for thread communication between audio and UI
- `AbstractFifo` for buffering between audio/MIDI threads
- Access shared state (recording flag, note index) atomically

### 6.6 Export Validation
- Verify at least one sample recorded before export
- Check disk space before writing
- Handle existing file overwrite (prompt user)
- Verify exported files are readable
- Use sample pack name to prevent naming conflicts

## File Format Specifications

### SFZ (Simple, Recommended)
- Text-based, human-readable
- Direct note-to-sample mapping via `key=` and `pitch_keycenter=`
- Minimal additional parameters needed
- **Reference**: sfzformat.com

### SF2 (SoundFont 2, Complex)
- Binary format with complex structure
- Requires sample rate conversion, preset/instrument definitions
- **Reference**: Creative Labs SoundFont specification
- **Complexity**: High (consider skipping if time-constrained)

### Decent Sampler (Modern, Simple)
- XML-based container format
- Flexible mapping and metadata
- **Reference**: Decent Samples documentation
- Audio embedded or external
